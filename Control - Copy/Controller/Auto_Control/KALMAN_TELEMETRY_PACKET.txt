================================================================================
  UART TELEMETRY PACKET REFERENCE
  Auto_Control Project — STM32G474RE Motor Controller
  Baud rate : 2 000 000 bps (2 Mbaud)
  Rate      : 1 000 Hz (one packet per TIM6 tick)
  Framing   : Header 0x7E 0x7E … Footer 0x03 0x03
  Byte order: Little-endian (ARM Cortex-M4)
  Float type: IEEE 754 single precision (32-bit)
================================================================================

  Two packet formats share the same header/footer.
  Switch is controlled by Live Expression variable:

      kalman_exp_enabled = 0  →  NORMAL packet   (76 bytes)
      kalman_exp_enabled = 1  →  KALMAN EXP packet (128 bytes)

================================================================================
  PACKET B — KALMAN EXPERIMENT TELEMETRY  (kalman_exp_enabled = 1)
  Total size : 128 bytes
================================================================================

  Activate via Live Expressions:
    kalman_exp_enabled = 1
    kf_exp_set_id      = 0.0  (running vary-R set)   OR
    kf_exp_set_id      = 1.0  (running vary-Q set)

  Waijung block setting:  Packet size = 128 bytes
  Same header 0x7E 0x7E and footer 0x03 0x03 as Packet A.

  SECTION 2 — KALMAN FILTER STATES (bytes 30–125)
  Each filter block = 16 bytes  (4 states × 4 bytes each)
  Order per block:  [position] [velocity] [current] [tau_d]
--------------------------------------------------------------------------------

  Filter configurations:
  ┌───────┬────────────┬─────────────┬─────────────────────────────────────────┐
  │ Index │  sigma_v²  │   r_theta   │  Experiment                             │
  ├───────┼────────────┼─────────────┼─────────────────────────────────────────┤
  │  [0]  │   0.01     │   1e-4      │  Fixed Q=0.01, R varied  (large R)      │
  │  [1]  │   0.01     │   1e-7      │  Fixed Q=0.01, R varied  (mid R)        │
  │  [2]  │   0.01     │   1e-10     │  Fixed Q=0.01, R varied  (small R)      │
  │  [3]  │   1.0      │   1e-7      │  Fixed R=1e-7, Q varied  (large Q)      │
  │  [4]  │   0.01     │   1e-7      │  Fixed R=1e-7, Q varied  (mid Q = [1])  │
  │  [5]  │   1e-5     │   1e-7      │  Fixed R=1e-7, Q varied  (small Q)      │
  └───────┴────────────┴─────────────┴─────────────────────────────────────────┘

================================================================================
  WAIJUNG SIMULINK BLOCK SETUP
================================================================================

  Normal telemetry  (kalman_exp_enabled = 0):
    Header        : 0x7E 0x7E
    Footer        : 0x03 0x03
    Packet size   : 76 bytes
    Payload bytes : 72  (bytes 2–73)

  Kalman experiment  (kalman_exp_enabled = 1):
    Header        : 0x7E 0x7E  (same — no Waijung reconfiguration of framing needed)
    Footer        : 0x03 0x03
    Packet size   : 128 bytes
    Payload bytes : 124  (bytes 2–125)

  When switching modes:
    1. Stop Simulink simulation
    2. Change Waijung UART Receive block  →  Packet size  76 ↔ 128
    3. Re-map signal extraction offsets per the tables above
    4. Restart simulation
    5. Set kalman_exp_enabled = 1 in Live Expressions

================================================================================
  WITHIN EACH 16-BYTE FILTER BLOCK  (offset relative to block start)
================================================================================

  +0  bytes  →  position   θ   (rad)
  +4  bytes  →  velocity   ω   (rad/s)
  +8  bytes  →  current    i   (A)
  +12 bytes  →  tau_d      τ   (N·m)

  Formula:  absolute_byte = 30 + (filter_index × 16) + signal_offset

  Examples:
    kf2_velocity  = byte  30 + (2×16) + 4  = byte  66
    kf5_tau_d     = byte  30 + (5×16) + 12 = byte 122
